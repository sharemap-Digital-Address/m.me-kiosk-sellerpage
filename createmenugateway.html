📌 Setup Your Menu Storage

Wala ka pang nakakabit na Google Sheet storage para sa iyong menu.

📱 PAALALA SA CELLPHONE / TABLET USERS:
Para hindi kusang magbukas ang Google Sheets App (na walang Apps Script menu):
Pumunta sa Phone Settings > Apps > Google Sheets > Open by default at i-OFF ito (o piliin ang Ask every time / Open in Browser).
💡 Paano makuha ang Link ng Blank Google Sheet?
1. Gumawa ng Blank Sheet sa Google Sheets / Drive.
2. I-click ang 3 dots (⋮) sa tabi ng sheet o sa Share / Copy Link.
3. Hindi na kailangang baguhin ang Manage Access (kahit Private/Restricted, okay lang).

⚙️ Huling Hakbang sa Web Browser

💡 Naka-copy na ang code at nabuksan na ang Sheet sa Browser!

1. Sa browser, siguraduhing naka-Desktop Site mode (3 dots > Desktop site).
2. Sa Google Sheet menu, i-click ang Extensions > Apps Script.
3. ⚠️ Burahin MUNA LAHAT ng nakasulat doon bago i-paste ang code.
4. 📱 TIPS SA MOBILE/TABLET PASTE: Sa mismong screen mag-long press at piliin ang Paste mula sa lalabas na pop-up menu ng screen (huwag gamitin ang paste button sa keyboard para hindi masira ang format).
5. I-click ang Deploy > New deployment, piliin ang Web app.
6. Sa Who has access, piliin ang Anyone at i-click ang Deploy.

function doPost(e) { var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); var data = JSON.parse(e.postData.contents); if (sheet.getLastRow() === 0) { sheet.appendRow(["Category", "Name", "Size", "Price", "Discount", "MixMatch_Type", "MixMatch_Target", "MixMatch_Discount", "Description", "Status", "Quantity", "Image"]); } if (data.action === "ADD_ITEM") { sheet.appendRow([ data.category, data.name, data.size, data.price, data.discount, data.mixMatchType, data.mixMatchTarget, data.mixMatchDiscount, data.description, data.status, data.quantity, data.image ]); return ContentService.createTextOutput(JSON.stringify({status: "SUCCESS"})).setMimeType(ContentService.MimeType.JSON); } } function doGet(e) { var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); var rows = sheet.getDataRange().getValues(); var items = []; for (var i = 1; i < rows.length; i++) { items.push({ category: rows[i][0], name: rows[i][1], size: rows[i][2], price: rows[i][3], discount: rows[i][4], mixMatchType: rows[i][5], mixMatchTarget: rows[i][6], mixMatchDiscount: rows[i][7], description: rows[i][8], status: rows[i][9], quantity: rows[i][10], image: rows[i][11] }); } return ContentService.createTextOutput(JSON.stringify(items)).setMimeType(ContentService.MimeType.JSON); }
